# Customer Churn Analysis — Rounds 2, 3 and 4

This pack groups the available project deliverables by assessment round. Round 1 is not included because it was described as a quiz.

## Folder guide

- `Round2_EDA_Feature_Engineering/` — notebook, EDA workbook, supporting charts, and Round 2 notes.
- `Round3_Excel_Analysis/` — corrected final Excel analysis workbook and submission notes.
- `Round4_Presentation/` — final presentation, speaker notes, and chart assets.
- `Shared_Datasets/` — source CSV files and cleaned dataset exports.

## Important notes

- The dataset is synthetic practice data, not real company data. Disclose this wherever relevant and confirm synthetic data is allowed for the assessment.
- Round 2 notebook requires `customers.csv`, `usage.csv`, `billing.csv`, `support.csv`, and `service.csv`. Copy these from `Shared_Datasets/` into the notebook's working directory, or update notebook paths before running it.
- The Round 2 notebook performs EDA and feature engineering. Do not claim model accuracy or F1 score unless a model has actually been trained and evaluated.
- Check the assessment instructions for the exact files required for submission.
