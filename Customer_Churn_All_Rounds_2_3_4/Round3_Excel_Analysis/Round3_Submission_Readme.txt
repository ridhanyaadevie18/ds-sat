ROUND 3 — DATA ANALYSIS USING EXCEL (30 MARKS)
Workbook: Round3_Corrected_Complete_Analysis.xlsx

Included:
- Cleaned_Data sheet
- Summary sheet with headline KPIs and key findings
- Six native Pivot Tables: Plan, TenureGroup, ComplaintGroup, PaymentStatus, Region, CustomerSegment
- Charts on analysis sheets and charts sourced from Pivot Table results
- Analysis sheets for churn by plan, tenure, complaints, payment behaviour, region, customer segments, and usage
- Statistical Summary with Excel formulas
- Formula Guide

Important data note:
The workbook uses synthetic practice data, not actual ConnectSphere Telecom records. The results are for demonstrating the analysis workflow only. Disclose this limitation and confirm that synthetic data is allowed before submission.

Recommended check:
Open the workbook in Excel or LibreOffice Calc. Select each Pivot Table and use Refresh if needed. The pivot tables use a helper column named CustomerCount (one per record) summed to count customer records, with Churn as the column field.
